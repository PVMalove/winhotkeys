# Слот 0 остаётся зарезервированным, но триггер по умолчанию выключен

Сегодня Alt+0 — единственный и жёстко зарезервированный способ открыть
меню; `validate_bind` явно запрещает пользователю занимать слот 0.
Новый дизайн предлагает 3 триггера открытия панели, и Alt+0 (в виде
триггера «Кастомная горячая клавиша») больше не обязателен — по умолчанию
включён триггер «Скольжение от края».

Рассматривались два варианта: (а) освободить слот 0 полностью, разрешив
привязывать его к приложениям как 1-9, или (б) оставить слот 0
зарезервированным, но сделать соответствующий триггер опциональным и
выключенным по умолчанию.

Выбран (б): слот 0 остаётся зарезервированным. Освобождение слота 0 (а)
потребовало бы менять инвариант `validate_bind` и семантику "1-9 = приложения"
во всей остальной кодовой базе ради опции, которая в новом дизайне и так
не является основным способом открытия панели.
