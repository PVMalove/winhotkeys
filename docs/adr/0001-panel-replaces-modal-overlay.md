# Панель заменяет модальный оверлей Alt+0

Сегодня `overlay.py` — модальный попап по центру экрана: спавнится заново
при каждом нажатии Alt+0 и закрывается по Esc/потере фокуса/выбору
приложения. У него нет постоянного состояния видимости.

Новый дизайн требует докованное у края окно с наведением на край и
автоскрытием по таймеру — оба сценария предполагают, что панель постоянно
"живёт" (resident) и сама решает, когда показаться и скрыться, а не
создаётся заново по каждому нажатию. Модальный попап-по-требованию такое
поведение выразить не может.

Решение: панель — новая архитектурная сущность (резидентное окно с
триггерами открытия и автоскрытием), а не рескин `overlay.py`. Реализация
`overlay.py` в её нынешнем виде — за рамками этой дизайн-сессии.
