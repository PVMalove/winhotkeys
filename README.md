# winhotkeys

Глобальные горячие клавиши для переключения между окнами программ на Windows.
Alt+1..9 — запуск/переключение привязанных программ. Боковая панель у края
экрана даёт быстрый доступ ко всем привязкам без горячих клавиш — как Dock
на macOS.

## Особенности

- Без AutoHotkey, pywin32 и прочих сторонних утилит — WinAPI напрямую через
  `ctypes` (`RegisterHotKey`, `EnumWindows`, `SetForegroundWindow`, ...).
- Alt+N: программа не запущена — запускается; запущена — фокус переходит на
  следующее окно по кругу; на последнем окне (или когда оно одно) повторное
  нажатие сворачивает вместо зацикливания.
- Резидентная боковая панель со всеми привязками (реальные иконки `.exe`,
  клик или цифра — переключиться/запустить): открывается скольжением от
  края экрана, наведением на край, либо — если явно включено в
  настройках — кастомной горячей клавишей Alt+0 (по умолчанию выключена,
  слот 0 всё равно зарезервирован под панель и недоступен для привязок).
  Автоматически скрывается по таймеру простоя, либо закрывается кнопкой.
- Окно настроек (`winhotkeys settings`) — способ открытия панели, сторона
  экрана, время автоскрытия.
- Включение/выключение, добавление своих привязок из консоли, покрыто
  тестами (`pytest`).

## Требования

- Windows, Python 3.8+
- `pip install -r requirements.txt` — сторонние зависимости
  (`customtkinter` + Pillow для окна настроек, `PySide6` для боковой
  панели), нужны только для GUI; без них переключение окон по Alt+1..9
  работает как есть.

## Быстрый старт

```powershell
pip install -r requirements.txt
python run.py start --foreground   # проверить слушатель Alt+1..9 (Ctrl+C — стоп)
python run.py start                # затем запустить в фоне: слушатель + панель
```

## Команды

| Команда | Действие |
|---|---|
| `start [--foreground]` | включить слушатель (Alt+1..9) и резидентную панель. `--foreground` — только слушатель, в текущей консоли, для отладки |
| `stop` | выключить слушатель и панель |
| `status` | статус и PID обоих процессов |
| `list` | показать текущие привязки |
| `add <номер> <имя> <команда> --process <имя_процесса> [--mod alt\|ctrl\|shift\|win]` | добавить/заменить привязку |
| `remove <номер>` | удалить привязку |
| `settings` | открыть окно настроек панели |

Привязки по умолчанию: Alt+1 — VS Code, Alt+2 — PowerShell 7. Номер — цифра
1–9 (0 зарезервирован под панель). После `add`/`remove`, а также после
изменения настроек панели, слушатель и панель нужно перезапустить (`stop`,
затем `start`).

Раздел «Управление Горячими Клавишами» в `settings` дублирует `add`/`list`/
`remove` в графическом виде: список всех привязок и кнопка «+ Добавить
приложение» с той же валидацией, что и у CLI.

## Конфигурация

Хранится в `%APPDATA%\winhotkeys\config.json`, создаётся автоматически:
привязки — в `binds`, поведение панели (`trigger`/`side`/`hide_delay`) — в
`panel`. Старые config.json (плоский список привязок без этих ключей)
читаются как есть — обёртка происходит автоматически при загрузке.

## Безопасность

Только штатные, документированные функции WinAPI — те же, что использует
сама оболочка Windows (Alt-Tab, панель задач). Сетевых вызовов нет, всё
работает локально.
