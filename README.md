# winhotkeys

Глобальные горячие клавиши для переключения между окнами программ на Windows.
Alt+1..9 — запуск/переключение привязанных программ, Alt+0 — меню всех
привязок в стиле macOS App Switcher (иконки, размытие, увеличение при
наведении).

## Особенности

- Без AutoHotkey, pywin32 и прочих сторонних утилит — WinAPI напрямую через
  `ctypes` (`RegisterHotKey`, `EnumWindows`, `SetForegroundWindow`, ...).
- Alt+N: программа не запущена — запускается; запущена — фокус переходит на
  следующее окно по кругу; на последнем окне (или когда оно одно) повторное
  нажатие сворачивает вместо зацикливания.
- Alt+0 — меню со всеми привязками: реальные иконки `.exe`, клик или цифра —
  сразу переключиться (или запустить) и закрыть.
- Включение/выключение, добавление своих привязок из консоли, покрыто
  тестами (`pytest`).

## Требования

- Windows, Python 3.8+
- `pip install -r requirements.txt` — единственная сторонняя зависимость
  (`customtkinter` + Pillow), нужна только для меню Alt+0; без неё
  переключение окон по Alt+1..9 работает как есть.

## Быстрый старт

```powershell
pip install -r requirements.txt
python run.py start --foreground   # проверить, что всё работает (Ctrl+C — стоп)
python run.py start                # затем запустить в фоне
```

## Команды

| Команда | Действие |
|---|---|
| `start [--foreground]` | включить прослушивание горячих клавиш |
| `stop` | выключить |
| `status` | статус и PID |
| `list` | показать текущие привязки |
| `add <номер> <имя> <команда> --process <имя_процесса> [--mod alt\|ctrl\|shift\|win]` | добавить/заменить привязку |
| `remove <номер>` | удалить привязку |

Привязки по умолчанию: Alt+1 — VS Code, Alt+2 — PowerShell 7. Номер — цифра
1–9 (0 зарезервирован под меню Alt+0). После `add`/`remove` слушатель нужно
перезапустить (`stop`, затем `start`).

## Конфигурация

Хранится в `%APPDATA%\winhotkeys\config.json`, создаётся автоматически.

## Безопасность

Только штатные, документированные функции WinAPI — те же, что использует
сама оболочка Windows (Alt-Tab, панель задач). Сетевых вызовов нет, всё
работает локально.
